## 大类定义

04_Intersection 路口通行
[A] 自车通过各类路口（信号灯控制、无信号、环岛等），涉及直行、转弯、掉头等不同通行方式。
[B] 你正在通过一个路口，可能是直走、左转、右转或掉头。
[C] 自车在路口的各种通行方式。

## 子标签定义

Intersection_ProtectedLeftTurn 有保护左转
[A] 自车在有左转专用信号灯保护下执行左转，对向直行车流被红灯拦截。
[B] 左转绿灯亮了，对面的车被红灯挡着，你可以放心左转。
[C] 有专用信号保护的左转。

Intersection_UnprotectedLeftTurn 无保护左转
[A] 路口没有信号灯（`any_traffic_light_visible=false`），自车在无任何信号灯控制的路口执行左转，需自行观察并让行对向直行车辆。判定必要条件：路口不存在红绿灯设施。若路口有信号灯但灯灭，属于 TrafficLight 大类的黑灯标签。

Intersection_ProtectedStraight 有保护路口直行
[A] 自车在直行绿灯保护下通过路口，交叉方向车流被红灯控制。

[C] 绿灯保护下的路口直行。

Intersection_UnprotectedStraight 无保护路口直行
[A] 路口没有信号灯（`any_traffic_light_visible=false`），自车在无任何信号灯控制的路口直行通过，需自行观察交叉方向车流。判定必要条件：路口不存在红绿灯设施。若路口有信号灯但灯灭，属于 TrafficLight 大类的黑灯标签。
[B] 路口根本没有红绿灯，你直行通过时得自己看清楚左右有没有来车再过。
[C] 路口无信号灯，自车自行观察后直行通过。

Intersection_MisalignedStraight 错位非对齐路口直行

[B] 这个路口对面的路不是正对着你的，过路口时得稍微拐一下才能接上对面的路。
[C] 进出口不对齐的错位路口直行。

Intersection_CongestedStraight 拥堵路口直行
[A] 路口出口方向拥堵，自车直行可能需在路口内等待或缓行通过。
[B] 路口对面堵着出不去，你直行过去可能会卡在路口中间。
[C] 出口拥堵时的路口直行。

Intersection_ProtectedRightTurn 有保护右转
[A] 自车在右转信号灯保护下执行右转。

Intersection_DedicatedRightTurnLane 右转专用道

[B] 有一条专门的右转车道，和直行道是分开的，你沿着它转就行。

Intersection_RightTurnWithNonMotorLane 右转右侧直行非机动车道

## 如何解读输入数据中的 traffic_light 字段（用于区分有保护/无保护）

输入 JSON 中 `traffic_control.traffic_light` 包含以下关键信息，判断"有保护"还是"无保护"时必须仔细阅读：

- **any_traffic_light_visible**（bool）：是否可见任何信号灯。
  - 若为 **false**：路口无信号灯控制 → 对应"无保护"类标签（UnprotectedLeftTurn / UnprotectedStraight / TJunctionUnprotectedMerge 等）
  - 若为 **true**：需进一步看灯头详细信息
- **heads[]**：每个灯头的状态：
  - **aspect_guess**：灯的颜色 → red / yellow / **green** / red_yellow / **off**（灭灯） / unknown
  - **arrow_direction_guess**：箭头方向 → **straight** / **left** / **right** / **uturn** / none / unknown
  - **is_flashing_guess**（bool）：是否闪烁
  - **visibility**：可见性 → clear / partial / occluded / not_visible

### "有保护"vs"无保护"的判断逻辑

- **有保护(Protected)**：`any_traffic_light_visible=true`，且存在与自车通行方向匹配的灯头（`arrow_direction_guess` 对应 straight/left/right），且该灯头 `aspect_guess=green`，表示自车方向受绿灯保护。
- **无保护(Unprotected)**：**仅当 `any_traffic_light_visible=false`（路口不存在信号灯设施）** 时，才判定为"无保护"类标签。
  - 注意以下情况**不属于**"无保护"：
    - 灯头 `aspect_guess=off`（黑灯）→ 路口有灯但灯灭，属于 **TrafficLight 大类的黑灯标签**
    - 灯头 `visibility=occluded`（被遮挡）→ 属于 **TrafficLight 大类的遮挡信号灯标签**

## 判断要点

1. 重点关注 **road_layout** 中是否为路口（intersection）、环岛（roundabout）、T型路口等。
2. **判断"有保护"还是"无保护"必须基于 traffic_light 字段的实际数据**，不能凭猜测。需同时确认：① `any_traffic_light_visible` 是否为 true；② 对应方向灯头的 `aspect_guess` 和 `arrow_direction_guess`。
3. 结合 **ego_motion** 判断自车通行方向（直行/左转/右转/掉头），再与灯头 `arrow_direction_guess` 匹配。
4. 关注 **lane_and_markings** 和 **road_layout** 判断是否有待转区、专用道、环岛等特殊结构。
5. 若该视频不涉及路口通行场景，tags 输出空列表。

### 字段说明
- **tags**：列表，包含该视频片段在 04_Intersection 大类下所有适用的子标签。
- **major_category**：固定为 04_Intersection。
- **sub_category / sub_category_en**：**必须来自上述子标签定义**，禁止自创。
- **is_other_subcategory**：**一律为 false**，禁止自创子类别。
- **time_evidence**：引用 Round-A 中 segments / agents 的时间区间。
- **visual_cues**：支撑该标签判定的关键可视线索。
- **confidence**：对该标签判定的确信度（major 和 sub 分别给出 0-1 的值）。
- **risk_level**：该标签对应场景的风险等级（low / medium / high）。
- **traffic_rule_keywords**：与该标签相关的交规关键词。
