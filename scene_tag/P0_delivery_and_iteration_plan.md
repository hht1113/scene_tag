## 三、P0 迭代线：36 类分层挖掘方案

> 详细方案见 `P1_label_mining_plan.md`，此处仅列执行计划

### 3.1 方案回顾

```
20秒视频 → 抽12帧拼网格图
→ Step 2: [235B] 事实抽取 + 一级组分类（6 组）
→ Step 3: [235B] 组内细分（4~10 个标签选 1）
→ × 3 次独立采样（temperature=0.3~0.5）
→ Step 4: 投票过滤（一级组一致 + 标签一致）
→ Step 5: 输出伪标签（high/medium/low）
```

每个视频 6 次 VLM 调用，500 视频 ≈ 3000 次调用 ≈ 2.5-4 小时（单机 8 卡）

### 3.2 需要交付的代码模块

| 模块 | 说明 | 优先级 |
|---|---|:---:|
| `frame_sampler.py` | 40 帧中均匀抽 12 帧，拼 3×4 网格图 | **P0** |
| `prompts/fact_and_group.txt` | 事实抽取 + 一级组分类 prompt | **P0** |
| `prompts/group_G2_fine.txt` | G2 路口内动态交互 组内细分 prompt（8 标签） | **P0** |
| `prompts/group_G4_fine.txt` | G4 路口通行 组内细分 prompt（10 标签） | **P0** |
| `vlm_inference.py` | VLM 推理封装（vLLM API + 多次采样） | **P0** |
| `vote_filter.py` | 多次采样投票 + 置信度分级 | **P0** |
| `export_dataset.py` | 导出最终伪标签数据集 | **P0** |
| `prompts/group_G1_fine.txt` | G1 红绿灯通行 组内细分 prompt（3 标签） | P1 |

### 3.3 优先组：G2 和 G4

按方案推荐顺序，先跑 **G2（路口内动态交互, 8 标签）** 和 **G4（路口通行, 10 标签）**：
- G2 覆盖路口内 VRU/车辆横穿、切入等高价值场景
- G4 覆盖有保护/无保护左转、直行、右转等路口通行场景
- 两组合计 18 个标签，占全部 36 标签的 50%
