# 人工判读表

> 使用说明：
> - 每个 prompt 类别挖掘完成后，按标签分组抽查 20 条
> - 逐条播放视频，判断模型标注是否正确
> - 记录错误原因，计算人工准确率 = 正确数 / 抽查数
> - 人工准确率 = 模型直接推理准确率

---

## 判读标准

| 判定 | 含义 |
|:---:|---|
| ✅ | 标注正确，标签和时间段均合理 |
| ❌ | 标注错误，记录错误原因 |
| ⚠️ | 边界模糊，标签有争议但可接受 |

## 常见错误原因分类

供填写参考，可直接复制粘贴：

| 错误代码 | 错误原因描述 |
|---|---|
| **标签混淆类** | |
| MIX-01 | 应为其他标签：___（填写正确标签） |
| MIX-02 | 与相似标签混淆（如直行↔左转、切入↔横穿） |
| MIX-03 | 应为 not_applicable / else，场景不匹配 |
| **时间段错误类** | |
| TIME-01 | 标注时间段偏移（实际发生时间不同） |
| TIME-02 | 时间段过长，包含了非相关片段 |
| TIME-03 | 时间段过短，遗漏了动作的起始/结束阶段 |
| **场景误判类** | |
| SCENE-01 | 目标存在但未与ego产生交互（如旁边车道通过但未切入） |
| SCENE-02 | 目标不存在（幻觉/误识别） |
| SCENE-03 | 场景发生在路口内，应使用IntersectionInteraction类标签 |
| SCENE-04 | ego静止等红灯，正常交通流不应标为interaction |
| **对象分类错误** | |
| OBJ-01 | 将VRU误判为Vehicle（或反之） |
| OBJ-02 | 对象类型识别错误（行人↔自行车↔电动车） |
