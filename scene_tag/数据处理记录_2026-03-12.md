## 3. 下载过程

### 3.1 数据来源

- **BOS Bucket**: `neolix-raw`

### 3.2 下载任务拆解

| 项目 | 数量 |

### 3.3 磁盘空间问题

下载过程中多次因磁盘满而中断：

| 轮次 | 问题 | 解决 |
|------|------|------|
| 第1次 | 200GB 满，无法启动下载 | 清理 saves/(64GB) 移到 `/mnt/pfs/houhaotian/saves/` |
| 第2次 | original_videos 膨胀到 70GB 撑满磁盘 | 删除 original_videos，修改脚本切片后自动删原始视频 |
| 第3次 | 同上问题 | 再次清理 original_videos |
| 第4次 | 脚本已自动删原始视频，空间稳定 | 成功完成 |

### 3.4 脚本修改

在 `1_download_from_bos_for_segment.py` 第 591-599 行添加了切片后自动删除原始视频的逻辑：

```python
if os.path.exists(local_video_path):
    os.remove(local_video_path)
    parent = os.path.dirname(local_video_path)
    while parent and parent != os.path.dirname(parent):
        if os.path.isdir(parent) and not os.listdir(parent):
            os.rmdir(parent)
            parent = os.path.dirname(parent)
        else:
            break
```

## 5. 数据集清理

因推理脚本（`av.open()`）遇到缺失文件会直接崩溃，不会跳过，所以从 JSON 中移除了引用缺失视频的样本。

处理方式：原地修改 JSON 文件，移除所有 `videos` 字段中文件不存在的样本。

| 数据集 | 清理前 | 清理后 | 移除 | 影响 |
|--------|--------|--------|------|------|
| train | 3624 | **3602** | 22 条 | 0.6% |
| test | 422 | **420** | 2 条 | 0.5% |

注意：train 移除 22 条（多于 11 个缺失视频），因为部分视频被多个样本引用（上采样导致的重复）。
